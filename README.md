# ED Planet Search

Интерактивный поисковик планет **Elite Dangerous** по данным [Spansh](https://spansh.co.uk/). Приложение помогает находить подходящие планеты по типу поверхности, атмосфере, температуре, гравитации и давлению, а также оценивает потенциальную выручку от экзобиологии по встроенному справочнику видов.

## Возможности

- Семь готовых сценариев поиска и собственные критерии.
- Фильтры по поверхности, атмосфере и физическим параметрам.
- Исключение планет, для которых Spansh зарегистрировал биологические сигналы.
- Фоновый поиск с отображением прогресса и отменой.
- Таблица результатов с сортировкой и подробностями выбранной планеты.
- Копирование имени системы для построения маршрута.
- Оценка потенциальной выручки экзобиологии с указанием неизвестных условий.

## Установка

Нужен установленный [Rust](https://www.rust-lang.org/tools/install) со стабильным toolchain.

Из корня репозитория:

```sh
cargo install --path .
```

Либо запустить без установки:

```sh
cargo run
```

При первом запуске Cargo разрешает версии зависимостей и загружает необходимые пакеты. Репозиторий намеренно не хранит `Cargo.lock`.

## Быстрый старт

Запустите приложение без аргументов:

```sh
ed_planet_search
```

Откроется экран поиска с первым сценарием и центральной системой Sol. Нажмите Enter, чтобы начать поиск. Клавиша F2 открывает дополнительные фильтры.

В приложении доступны семь сценариев:

| № | Сценарий | Температура | Потенциал профиля |
|---:|---|---:|---:|
| 1 | CO₂ · каменистые | 190–195 K | 363 млн CR |
| 2 | CO₂ · каменистые | 180–190 K | 166 млн CR |
| 3 | Вода · каменистые и с высоким содержанием металлов | 395–450 K | 279 млн CR |
| 4 | Аммиак · каменистые | 165–175 K | 94 млн CR |
| 5 | Аргон · ледяные | 50–150 K | 65 млн CR |
| 6 | SO₂ · каменистые | 132–195 K | 141 млн CR |
| 7 | Кислород · ледяные | 145–270 K | 111 млн CR |

Значения потенциала — справочная оценка сценария, а не гарантированная награда.

## Управление

| Клавиша | Действие |
|---|---|
| ↑ / ↓ | Выбор сценария, значения или планеты |
| Tab / Shift+Tab | Перейти к следующему / предыдущему полю |
| Enter | Запустить поиск или подтвердить действие |
| F2 | Показать / скрыть дополнительные фильтры |
| Пробел | Переключить флаг или тип поверхности |
| Home / End | Перейти в начало / конец текстового поля |
| Backspace / Delete | Удалить символ |
| Вставка текста | Вставить текст в активное поле |
| Esc | Отменить поиск или вернуться к настройке |
| ? | Открыть справку текущего экрана |
| Ctrl+Q | Выйти из приложения |
| s / ы | Переключить столбец сортировки результатов |
| S / Ы | Изменить направление сортировки |
| c / с | Скопировать имя системы выбранной планеты |
| e / у | Изменить параметры поиска |
| n / т | Начать новый поиск |
| PgUp / PgDn | Прокрутить подробности планеты |
| r / к | Повторить поиск после ошибки |

Буквенные команды поддерживают английскую и русскую раскладки. Копирование использует OSC 52; если терминал не поддерживает этот механизм, имя системы можно выделить и скопировать вручную.

## Запуск через командную строку

Для неинтерактивного запуска передайте центральную систему, тип поверхности и атмосферу:

```sh
ed_planet_search \
  --system "Sol" \
  --planet-type "rocky body" \
  --atmosphere-type "carbon dioxide" \
  --temperature "190-195" \
  --gravity "0.1-1.0" \
  --pressure "0.042-0.237" \
  --count 5 \
  --exclude-with-bio-signals
```

Короткие варианты обязательных параметров: `-S` (система), `-P` (поверхность), `-A` (атмосфера). Остальные параметры:

| Параметр | По умолчанию | Назначение |
|---|---:|---|
| `-t, --temperature` | `0-5000` | Диапазон температуры в K |
| `-g, --gravity` | `0.1-1.0` | Диапазон гравитации |
| `-p, --pressure` | `0.0-10.0` | Диапазон давления |
| `-c, --count` | `5` | Требуемое количество планет |
| `--exclude-with-bio-signals` | выключен | Исключить планеты с зарегистрированными Spansh биосигналами |

Для поверхности принимаются `any`, `rocky body`, `icy body`, `rocky ice world`, `high metal content world` (также поддерживаются короткие исторические варианты). Для атмосферы — `any`, `ammonia`, `water`, `carbon dioxide`, `sulphur dioxide`, `nitrogen`, `water-rich`, `methane-rich`, `carbon dioxide-rich`, `methane`, `helium`, `silicate vapour`, `neon-rich`, `argon-rich`, `neon`, `argon`, `oxygen`.

Посмотреть полный список аргументов можно командой:

```sh
ed_planet_search --help
```

## Источник данных и ограничения

- Данные о системах и планетах загружаются из Spansh; доступность и полнота результатов зависят от внешнего сервиса.
- Радиус поиска задаётся в форме сразу после центральной системы: по умолчанию **1000 св. лет**, допустимый диапазон — **1–5000 св. лет**.
- Наличие биологических сигналов отражает сведения Spansh и само по себе не доказывает, что планета была посещена или полностью исследована.
- Оценка экзобиологии — потенциальная базовая выручка по известным условиям справочника, а не прогноз вероятности обнаружения. Неизвестные условия отмечаются отдельно.
- Для оценки First Logged показан отдельный условный сценарий; фактическая выплата зависит от игровых обстоятельств.
- TLS проверяется с корневыми сертификатами WebPKI, поставляемыми Rust-зависимостью; системный пакет `ca-certificates` не требуется.
