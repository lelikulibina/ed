# Архитектура ED Planet Search

## Назначение и границы

ED Planet Search — Rust-приложение для поиска планет в Elite Dangerous по данным внешнего сервиса Spansh. Приложение не поддерживает локальную копию галактической базы. Сетевые данные загружаются по запросу, нормализуются в доменные модели и отображаются в терминальном интерфейсе.

## Слои

```text
main / cli
  └─ presentation (TUI, события, состояние, отрисовка)
       └─ application (форма, пресеты, сценарий поиска)
            ├─ domain (критерии, планеты, каталог)
            └─ spansh (HTTP, resolver, запросы, пагинация)
```

- **domain** содержит типы поверхности и атмосферы, диапазоны критериев, модель планеты и расчёт экзобиологии. Он не зависит от терминала и HTTP.
- **application** преобразует ввод формы в проверенную конфигурацию, предоставляет семь пресетов и координирует разрешение системы и поиск.
- **spansh** отвечает за HTTP-клиент, разрешение центральной системы, построение запросов, разбор ответов и постраничную загрузку.
- **presentation** содержит состояние приложения, обработку событий клавиатуры, команды, экраны и виджеты ratatui. Отрисовка читает состояние; переходы состояния обрабатываются централизованно.
- **cli** разбирает совместимые аргументы командной строки и преобразует их в ту же конфигурацию, что использует TUI.

Зависимости направлены внутрь: presentation → application → domain. Интеграция Spansh находится на границе application; домен не знает о сетевом API.

## Поток поиска

1. CLI или форма создаёт `SearchConfig`; диапазоны и обязательные поля проверяются до запуска.
2. `SystemResolver` ищет центральную систему через `GET /api/systems/field_values/system_names?q=…`. Сначала выбирается точное совпадение имени; при отсутствии — последовательно проверяются варианты имени без конечных компонентов. Если ответ не содержит ID64 или координат, запрашивается `GET /api/system/{id64}`.
3. `BodySearchQuery` формирует запрос с координатами центра и радиусом 1000 св. лет.
4. `BodySearch` отправляет `POST /api/bodies/search`. Следующие страницы загружаются через `GET /api/bodies/search/recall/{search_reference}/{page}`; если reference отсутствует или recall временно недоступен (404/405/410/5xx), используется POST с увеличенным номером страницы.
5. Ответы преобразуются в `Body`, дубликаты удаляются по ID64. Центральная система исключается, радиус и пользовательские критерии проверяются локально; поиск останавливается после набора заданного количества совпадений или конца выдачи.
6. События разрешения системы и загрузки страниц передаются в TUI; готовый список отображается в таблице с подробностями и оценкой экзобиологии.

## Сетевой клиент и отказоустойчивость

- Все HTTP-запросы проходят через `SpanshClient`; прямые запросы из presentation запрещены.
- Таймаут соединения — 5 секунд, общий таймаут запроса — 30 секунд.
- Одновременно выполняется не более одного запроса; между началами запросов выдерживается интервал не менее одной секунды.
- Для временных сетевых ошибок, HTTP 429 и 5xx предусмотрены ограниченные повторы.
- Пагинация использует размер страницы 100 и защитный предел 1000 страниц. Если предел достигнут до подтверждённого конца выдачи, возвращается ошибка о потенциально неполных результатах.
- ID64 хранится строкой, чтобы не терять точность больших идентификаторов.

## Ограничения и неопределённость API

Spansh — внешний источник, его данные могут быть неполными или устаревшими. Контракт API документирован не полностью и может меняться. Единицы температуры — Kelvin; гравитация — в g. Единицы давления требуют независимого подтверждения. Полнота выдачи сверх наблюдаемого лимита провайдера также не считается гарантированной.

Радиус 1000 св. лет задан в реализации и не настраивается пользователем. Фильтр биосигналов отражает зарегистрированные Spansh сведения и не доказывает факт посещения или полного исследования планеты.

## Проверки

Из корня репозитория:

```sh
cargo fmt -- --check
cargo clippy --all-targets --all-features -- -D warnings
cargo test --all-targets
```

Live-проверка Spansh находится отдельно в `tests/live_spansh.rs` и запускается вручную.
