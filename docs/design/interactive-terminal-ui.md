# Рефакторинг интерактивного терминального интерфейса

**Статус:** реализация TUI начата; требуется завершить UX-проверку и CI  
**Базовая ветка:** feature/preset-terminal-ui  
**Рабочая ветка:** feature/interactive-terminal-ui

## Цель

Заменить последовательный ANSI-опросник на полноценный интерактивный TUI. Интерфейс должен позволять выбирать профиль, видеть его параметры, менять параметры поиска, возвращаться между экранами и подтверждать запуск без повторного ввода всего набора значений.

## UX и компоновка

### Главный экран

- Верхняя строка: ED: PLANET SEARCH, версия и краткий статус.
- Левая панель: семь пресетов и пункт «Своя конфигурация».
- Правая панель: подробности выделенного пресета и справочные значения.
- Нижняя панель: форма запуска — центральная система, радиус (если поддерживается текущим поиском), лимит результатов, гравитация и исключение тел с зарегистрированными биосигналами.
- Нижняя строка клавиш: стрелки — навигация по профилям, Tab / Shift+Tab — переход по полям, Enter — выбрать профиль, Space — переключатель, F2 — ручная настройка, F5 — подтверждение поиска, Esc — назад, Ctrl+Q — выход.

### Ручная настройка

Отдельный экран с полями:
- тип поверхности (включая any);
- атмосфера (включая any);
- температура, K;
- гравитация, g;
- давление, atm;
- количество результатов;
- исключение тел с зарегистрированными биосигналами.

Поля должны валидироваться до запуска; ошибочное значение не должно теряться или молча заменяться default.

### Подтверждение

Перед сетевым запросом показывать компактную сводку всех применяемых критериев. Пользователь может подтвердить запуск или вернуться к редактированию.

## Сохранение поведения

- Существующий CLI при передаче аргументов остаётся неизменным.
- Сохраняются все семь профилей и точные числовые значения.
- Для профиля 3 типы поверхности остаются альтернативами OR.
- Вулканизм не становится фильтром ни для одного профиля.
- Гравитация в пресетах сохраняет текущий диапазон 0.1–1.0 g.
- Количество дорогих видов и потенциальная стоимость — только справочная информация.
- Переключатель исключения тел с зарегистрированными биосигналами остаётся независимым от профиля.

## Технический подход

- Использовать Ratatui + Crossterm для полноэкранного интерфейса, обработки клавиатуры, адаптивной раскладки и восстановления терминала.
- Вынести состояние UI и обработчики событий в presentation layer.
- Отделить преобразование формы в SearchCriteria от отрисовки.
- При ширине менее 90 колонок использовать вертикальную компоновку.
- RAII/guard должен восстанавливать alternate screen, raw mode и cursor даже при ошибке.
- Не менять SearchUseCase и алгоритм поиска.

## Проверки

- Unit-тесты преобразования формы в SearchCriteria и валидации диапазонов.
- Тесты навигации, выбора профиля, переключателя биосигналов и возврата.
- Сохранение CLI-поведения и проверки --help/--version.
- cargo fmt, clippy с -D warnings, cargo test --locked.
